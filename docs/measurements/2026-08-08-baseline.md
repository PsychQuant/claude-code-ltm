# 量測基線（2026-08-08）

設計決策依據的實測數字。**這些不是估計，是跑出來的**；方法與誤差一併記錄，
數字過期時才知道要重測什麼。

機器：MacBook Pro M5 Max，18 核（6E + 12P），128 GB unified memory，macOS 27.0（build 26A5388g）。

## 語料規模

| 項目 | 數值 | 方法 |
|---|---|---|
| jsonl 檔數 | 6,058 | `glob ~/.claude/projects/**/*.jsonl` |
| 原始總量 | 3.72 GB | `os.path.getsize` 加總 |
| 對話 text block | 約 59,700 | 抽樣 60 檔（18 MB）外推 |
| 對話純文字 | 約 142 M 字元（0.14 GB） | 同上 |
| **對話占原始體積** | **3.8%** | 0.14 / 3.72 |
| 平均每 block | 2,386 字元 | 抽樣 |

「對話 text block」＝ `type` 為 `user`／`assistant` 且 content 內 `type == "text"`
的區塊；**不含** `tool_use`／`tool_result`／`attachment`／`file-history-*`。

**誤差**：60 檔抽樣外推，未做信賴區間。單一 session 的獨立量測顯示對話占比 13.9%
（該 session 工具用量偏低），與全庫 3.8% 的差距說明**專案間變異很大**，外推值只該
當數量級用。

## 索引推估

切成約 500 字元的 chunk 後：

| 項目 | 數值 |
|---|---|
| chunk 數 | 約 280,000 |
| 向量體積 | 280k × 512 × 4 B = **583 MB**（mmap） |
| 單次查詢的暴力 cosine | 280k × 512 ≈ 1.46 億次乘加 |

**結論：不需要 ANN 索引。** 用 Accelerate（`cblas_sgemv`）暴力算是毫秒級。省掉 ANN
＝省掉額外依賴、參數調校、近似召回損失、以及重建邏輯。語料規模小到可以用最笨的
方法，而笨方法沒有調錯的空間。等超過幾百萬 chunk 再議。

## On-device 能力驗證

```swift
NLEmbedding.sentenceEmbedding(for: .traditionalChinese)   // nil  ← 中文不支援，不能用
NLEmbedding.sentenceEmbedding(for: .simplifiedChinese)    // nil
NLEmbedding.sentenceEmbedding(for: .english)              // OK dim=512
NLContextualEmbedding(script: .traditionalChinese)        // dim=512 rev=1 hasAssets=true
NLContextualEmbedding(script: .simplifiedChinese)         // dim=512 rev=1 hasAssets=true
NLContextualEmbedding(script: .latin)                     // dim=512 rev=1 hasAssets=true
import FoundationModels                                    // OK（macOS 27.0）
```

**要點**：舊的 `NLEmbedding.sentenceEmbedding` 對中文回 `nil`，用它會靜默拿不到向量。
必須用 `NLContextualEmbedding`，且它 `hasAssets=true`——模型已隨系統在本機，無需下載。

## Embedding 吞吐

| 項目 | 數值 |
|---|---|
| 樣本 | 200 段中英夾雜文字，每段約 180 字元 |
| 耗時 | 1.77 s |
| 吞吐 | **112.9 段/秒**，約 15,800 token/s（seqLen≈140） |

**外推的誠實邊界**：benchmark 每段約 180 字元，真實 chunk 目標長度 500 字元，成本隨
token 數增長，所以**實際會慢於 112 段/秒**。按 token 推算全量約 9,500 萬 token，
**首次全量建索引約 1.5–2 小時**。之後增量只跑新 session，每次數秒。

這個數字讓「索引可拋棄」從原則變成可行：全量重建是一個晚上的事，不是不可承受的成本。

## 重測觸發

- macOS 大版本更新（`NLContextualEmbedding` 的 `revision` 可能變，向量不可跨版本比較）
- 語料成長超過一個數量級（chunk 數逼近百萬時重估 ANN 的必要性）
- 換機器
